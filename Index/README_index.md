# MyTools 首页优化版

## 部署到原 GitHub Pages

将本包 `Index` 目录中的文件复制到 `i3doit/MyTools` 仓库的 `Index` 目录，提交后等待 GitHub Pages 部署完成。保留目录结构：

```
Index/
  index-sql8.html
  home.css
  home.js
  tools_init.sql
  vendor/
    sql-wasm.js
    sql-wasm.wasm
    lucide.js
```

原访问地址保持不变。不能只上传 HTML；CSS、JS 和 vendor 必须一起上传。请通过 HTTP 服务或 GitHub Pages 访问，直接双击 HTML 会受到浏览器对 SQL / WASM 文件读取的限制。

## SQL 数据维护

继续编辑同目录的 `tools_init.sql`，表结构和现有字段保持兼容，本包包含下载时的原始 SQL（31 条工具），未修改原数据。若仓库 SQL 在此期间有更新，部署时保留仓库最新版。

普通访问会从 SQL 构建新数据库，再应用当前浏览器的收藏偏好。网络失败时使用之前的缓存；初次加载失败不会保存空缓存。

旧版已有的非空数据库会优先保留，以避免丢失本地编辑。连续点击右上角设置按钮五次可切换本地管理，导出 SQL 备份；点击“刷新数据”可明确切换至仓库数据。本地编辑、导入或排序后，自动加载会保留本地数据库，直到用户确认刷新。

收藏保存在当前浏览器，不会自动同步到其他设备。导入 SQL 沿用“执行脚本”方式，JSON 追加，SQLite 替换；导入先在独立数据库验证，失败不会影响当前数据库。

## 主要改动

- 重做搜索、分类标签、收藏和卡片布局，适配手机及桌面。
- 移除运行时 Tailwind CDN；SQLite / WASM 与固定版本图标库随站点部署。
- 修复 SQLite 导入时 SQL 变量作用域、空缓存、SQL 更新不可见和分类失效问题。
- 支持名称、描述、分类和地址搜索；提供加载失败重试、离线提示和复制提示。
- 工具文本进行转义，链接限制为 HTTP / HTTPS，外部链接使用 noopener。
- 收藏、排序、新增、编辑、删除保护、访问设置、草稿、SQL 和 SQLite 导出继续可用。

访问设置和五次点击管理入口属于客户端显示与编辑控制。与原版一样，公开 SQL 的内容可被下载；实际访问鉴权应由目标工具提供。
