使用说明与数据保存

无需联网，双击本文件即可使用。任务和随手记自动保存到当前浏览器；Ctrl / ⌘ + S 可立即保存。P0 表示优先必做，P1 表示常规任务。智能排序会将进行中、优先必做和临近截止的事项排在前面。

专注计时从开始到暂停按实际时间累计，刷新或关闭页面后仍会继续；离开前可主动暂停。切换到另一任务会自动暂停当前任务，无需先完成。所有暂停任务默认每 5 分钟提醒，可通过顶部铃铛调整间隔、声音与轻晃提示，或关闭提醒。删除、清理和导入可在提示条中撤销。

浏览器本地数据不会随 HTML 文件移动，也不会自动同步到手机。更换浏览器、路径或设备前，请导出 JSON 备份，再在新位置导入。支持这三个旧版本导出的 JSON。请固定使用一个文件位置、一个浏览器，并避免同时打开多个窗口编辑。

随手记「转任务」按非空行生成任务；可以选中文字，也可以在弹窗中勾选一条或多条。复制图标会复制选中文字；未选中时打开条目选择窗口，可单条或批量复制。原笔记保留。全局搜索不受任务筛选影响，同时搜索全部任务、备注与随手记；点击结果可定位。今日到期包含今日及逾期任务。全部统计均基于完整清单；「导出文本」则导出当前筛选的全部匹配任务与随手记。

适配电脑、平板和手机的主流现代浏览器。部分手机文件管理器只提供 HTML 静态预览，请选择能执行网页脚本的浏览器打开，或通过网页地址访问。浏览器禁用本地存储时仍可临时记录，请使用 JSON 备份保存。
